CHAPTER 0

역할과 공통 화면 구성

포털 주소의 기본 언어는 한국어입니다. 예: /ko/login. 로그인하지 않은 사용자는 로그인 화면으로 이동하고, 로그인한 사용자는 홈으로 이동합니다.

학생

수강신청, 성적 확인, 본인 학적 조회. 가입 시 기본 역할입니다.

교수

담당 강의의 수강생 성적·이수 상태를 입력하고, 담당 학생의 학적을 조회합니다.

관리자

사용자·강의·학적 기록을 생성·수정하고 공지와 변경 이력을 관리합니다.

메뉴는 역할마다 다릅니다.

상단 헤더 · 프로필 메뉴

모든 로그인 화면에 공통으로 표시됩니다.

공통

왼쪽에는 학적부, 학교명(남미연합성결신학교), 현재 학년도·학기가 보입니다. 오른쪽에는 언어 전환과 내 이름 메뉴가 있습니다.

언어 전환 (ko / en / es)현재 화면을 유지한 채 표시 언어만 바꿉니다.
이름 이니셜 버튼눌러서 하위 메뉴를 엽니다.
비밀번호 변경비밀번호 변경 화면으로 이동합니다.
로그아웃세션을 종료하고 로그인 화면으로 돌아갑니다.

권한이 없는 주소로 들어가면 해당 기능을 사용할 수 없습니다. 메뉴에 없는 화면은 역할에 맞지 않는 기능입니다.

CHAPTER 1 · 공개 화면

로그인 전 화면

1. 로그인

/ko/login

공개

포털에 들어가기 위한 첫 화면입니다. 이미 발급받은 이메일과 비밀번호로 접속합니다.

이메일가입 시 사용한 이메일. 필수.
비밀번호계정 비밀번호. 필수.
로그인 버튼인증이 성공하면 홈으로 이동합니다.
회원가입 링크계정이 없으면 가입 화면으로 이동합니다.
개인정보 이용약관개인정보 처리 안내를 읽습니다.
  1. 이메일과 비밀번호를 입력합니다.
  2. 로그인을 누릅니다.
  3. 홈 화면이 열리면 역할에 맞는 메뉴를 사용합니다.

이메일·비밀번호가 틀리거나, 관리자가 계정을 사용안함으로 두면 로그인할 수 없습니다. 사용 중지 안내는 관리자에게 문의하세요.

2. 회원가입

/ko/register

공개

새 계정을 만듭니다. 가입 직후 역할은 학생입니다. 교수·관리자 권한은 관리자가 부여합니다.

이름포털에 표시될 이름. 필수.
이메일로그인 ID로 사용됩니다. 필수.
비밀번호새 비밀번호. 필수.
비밀번호 확인위와 같아야 합니다. 필수.
  1. 이름, 이메일, 비밀번호를 입력합니다.
  2. 비밀번호 확인이 일치하는지 확인합니다.
  3. 회원가입을 누릅니다.
  4. 안내가 나오면 이메일을 확인한 뒤 로그인합니다.

학교 정책에 따라 이메일 확인이 필요할 수 있습니다. 확인 메일이 오지 않으면 스팸함을 확인하거나 관리자에게 문의하세요.

3. 개인정보 이용약관

/ko/privacy

공개

로그인 없이 볼 수 있는 안내 문서입니다. 수집 항목, 이용 목적, 보유 기간, 이용자 권리, 문의처가 정리되어 있습니다.

로그인·회원가입 화면 하단의 개인정보 이용약관 링크로 들어옵니다. 읽기 전용이며 입력 항목은 없습니다.

CHAPTER 2 · 공통

모든 로그인 사용자 화면

4. 홈

/ko/home

학생 · 교수 · 관리자

로그인 후 처음 열리는 화면입니다. 환영 문구, 한눈에 보기, 바로가기, 최근 공지가 표시됩니다.

학생 요약현재 학적 상태, 수강 중인 강의 수, 내 학적 보기 버튼.
교수 요약담당 강의 수, 성적 입력이 필요한 건수, 담당 강의 관리 버튼.
관리자 요약사용자·강의·학적 기록 수, 사용자 관리 버튼, 최근 변경 5건.
바로가기내 역할 메뉴 중 홈·공지를 제외한 주요 화면 링크.
공지최근 공지 3건. 제목을 누르면 상세로 이동합니다.

성적 입력 필요는 점수가 비어 있거나, 수강 상태가 신청/수강 중인데 점수가 0인 경우를 셉니다.

5. 프로필

/ko/profile

학생 · 교수 · 관리자

본인 개인정보와 교회 정보를 확인하고 수정합니다. 이메일은 로그인 계정이라 이 화면에서 바꿀 수 없습니다.

프로필 사진JPG 또는 PNG, 최대 2MB. 사진 업로드로 바로 반영됩니다.
이름필수. 헤더와 목록에 표시됩니다.
생년월일 / 직업 / 휴대전화선택 입력.
학번 · 재학학기학생만 표시됩니다.
국적국가 목록에서 선택합니다.
주소직접 입력하거나, 키워드로 기존 주소를 검색해 고릅니다.
성별 / 교회명 / 직분선택 입력.
사용 언어한국어, 영어, 스페인어 중 선호 언어.
  1. 사진을 바꾸려면 파일을 고르고 업로드합니다.
  2. 나머지 항목을 수정합니다. 이름은 반드시 남겨 둡니다.
  3. 프로필 저장을 누릅니다.

6. 비밀번호 변경

/ko/change-password

학생 · 교수 · 관리자

헤더의 이름 메뉴 → 비밀번호 변경으로 들어옵니다. 로그인이 되어 있어야 합니다.

새 비밀번호앞으로 사용할 비밀번호.
비밀번호 확인새 비밀번호와 같아야 합니다.
  1. 새 비밀번호를 두 칸에 동일하게 입력합니다.
  2. 비밀번호 변경을 누릅니다.
  3. 완료되면 홈으로 돌아가기로 홈에 갑니다.

7. 공지사항 목록

/ko/notices

학생 · 교수 · 관리자

학교 공지를 최신순으로 봅니다. 제목을 누르면 상세 화면으로 이동합니다.

관리자에게만 목록 아래에 공지 작성 폼이 보입니다. 제목과 내용을 입력하고 공지 등록을 누르면 새 공지가 올라갑니다.

8. 공지 상세

/ko/notices/[id]

학생 · 교수 · 관리자

공지 제목, 등록일, 본문을 읽습니다. 공지 목록으로로 돌아갑니다.

관리자는 같은 화면에서 제목·내용을 고친 뒤 변경사항 저장하거나, 확인 후 삭제할 수 있습니다. 삭제는 되돌릴 수 없습니다.

CHAPTER 3 · 학생

학생 전용 화면

9. 수강신청

/ko/enroll

학생

개설된 강의를 표로 보고 신청합니다. 기간 제한 없이 열려 있는 강의에 언제든 신청할 수 있습니다.

강의명 / 담당 교수과목 이름과 교수 이름.
학기예: 2026년 1학기.
학점해당 강의 학점.
수강신청아직 신청하지 않은 강의에 표시됩니다.
신청 완료이미 신청한 강의. 다시 누를 수 없습니다.
  1. 원하는 강의 행의 수강신청을 누릅니다.
  2. 완료 메시지가 나오면 해당 행은 신청 완료로 바뀝니다.
  3. 성적·이수 결과는 내 성적에서 확인합니다.

같은 강의를 두 번 신청할 수 없습니다. 취소는 이 화면에서 하지 않으며, 필요하면 관리자에게 요청하세요.

10. 내 성적

/ko/grades

학생

내가 신청한 강의의 수강 상태, 점수, 이수 여부를 확인하는 읽기 전용 화면입니다. 점수는 교수가 입력합니다.

강의명 / 학기 / 학점수강한 과목 정보.
상태신청, 수강 중, 수료, 미수료, 취소.
점수0–100. 아직 없으면 “-”.
이수 여부이수 또는 미이수.

수강·성적 내역이 없으면 안내 문구만 보입니다. 먼저 수강신청을 완료하세요.

11. 내 학적

/ko/enrollment

학생

본인 학적 현황, 상태 변경 이력, 수강 강의를 한곳에서 봅니다. 수정은 할 수 없고 관리자가 기록을 남깁니다.

현재 학적학번, 재학학기, 학적 상태(입학·재학·휴학·제적·졸업), 학년, 연도/학기, 입학·졸업 정보.
학적 타임라인상태 변경 시각, 이전→이후 상태, 변경 사유, 휴학 기간, 지도교수.
수강 강의신청한 과목의 학기, 학점, 수강 상태, 점수, 이수.

학적 상태가 비어 있으면 아직 관리자가 학적 기록을 만들지 않은 것입니다.

13. 강의 수강생 · 성적 입력

/ko/teaching/[courseId]

교수

선택한 강의의 수강생 명단에서 점수와 수강 상태를 저장합니다. 본인 담당 강의가 아니면 열 수 없습니다.

학생이름. 누르면 해당 학생의 학적 조회 화면으로 갑니다.
이메일학생 연락용 이메일.
점수0부터 100 사이 정수.
수강 상태신청 / 수강 중 / 수료 / 미수료 / 취소.
이수체크하면 이수로 기록됩니다.
저장해당 학생 행만 저장합니다.
  1. 담당 강의 목록에서 과목 이름을 누릅니다.
  2. 학생별로 점수, 상태, 이수 여부를 입력합니다.
  3. 행의 저장을 누릅니다. 성공 메시지가 보이면 반영된 것입니다.

점수는 0–100 정수만 허용됩니다. 범위를 벗어나면 저장되지 않습니다.

학생 대리 수강신청학생에게만 표시. 강의 선택 후 대신 신청합니다.

자기 자신의 계정은 이 화면에서 사용안함으로 두거나 삭제할 수 없습니다. 실수로 잠기는 일을 막기 위한 제한입니다.

검색강의명으로 찾습니다.

삭제확인 후 강의를 지웁니다.
교수 필터사용자 상세에서 들어오면 해당 교수 강의만 보입니다. 필터 해제로 전체 목록으로 돌아갑니다.

강의 생성

강의명필수.
담당 교수교수 역할 사용자만 선택할 수 있습니다.

교수 계정이 하나도 없으면 강의를 만들 수 없습니다. 먼저 사용자 관리에서 교수를 생성하세요.

19. 학적 관리

/ko/admin/enrollments

관리자

학생별 학적 기록(입학·재학·휴학 등)을 만들고 목록에서 관리합니다. 수강신청과는 다른, 학적 상태 기록입니다.

목록학생 이름, 학년, 연도/학기, 학적 상태, 삭제.
학생 이름누르면 해당 기록의 상세·타임라인으로 갑니다.
학생 필터사용자 상세에서 들어오면 그 학생 기록만 보입니다.

학적 기록 생성

학생필수. 생성 후에는 학생을 바꿀 수 없습니다.
학년 / 연도 / 학기연도·학기는 필수. 학기는 1 또는 2.
학적 상태입학, 재학, 휴학, 제적, 졸업.
입학 정보 / 졸업 정보필요 시 메모.
변경 사유상태 변경 이유를 적습니다.
휴학 시작일 · 종료일휴학일 때 기간을 넣습니다.
지도교수지정하지 않아도 됩니다.

학생 계정이 없으면 학적 기록을 만들 수 없습니다.

20. 학적 상세

/ko/admin/enrollments/[id]

관리자

한 학적 기록을 수정하고, 그 학생의 전체 변경 이력과 수강 강의를 함께 봅니다.

학적 기록 수정생성 폼과 같은 항목. 학생은 변경할 수 없습니다. 변경사항 저장.
학적 타임라인상태 변경 시각, 이전→이후, 사유, 휴학 기간, 지도교수.
수강 강의해당 학생이 신청한 과목의 상태·점수·이수.

학적 상태를 바꾸면 변경 이력이 타임라인에 쌓입니다. 학생의 내 학적 화면에도 같은 이력이 보입니다.

21. 최근 변경

/ko/admin/change-logs

관리자

사용자·강의·학적 등 주요 데이터의 변경을 감사 로그로 확인합니다. 수정할 수 없는 조회 화면입니다.

일시변경이 기록된 시각.
사용자작업을 수행한 사람. 없으면 “알 수 없는 사용자”.
작업시스템 동작 코드(생성, 수정, 삭제 등).
대상바뀐 데이터 종류.
내용사람이 읽기 쉬운 요약.

하단의 이전·다음으로 페이지를 넘깁니다. 홈의 최근 변경은 여기서 전체 목록으로 이어집니다.
